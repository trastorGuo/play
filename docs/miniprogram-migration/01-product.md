# 产品与交互方案

## 1. 信息架构

```text
启动/登录
  └─ 首页
      ├─ 创建房间
      ├─ 加入房间
      ├─ 最近房间
      └─ 我的
          ├─ 历史房间
          ├─ 用户协议
          ├─ 隐私政策
          └─ 问题反馈

房间
  ├─ 成员与余额
  ├─ 新增记账
  ├─ 房间动态
  ├─ 全部流水
  ├─ 分享
  ├─ 设置
  └─ 结算
```

## 2. 页面定义

### 2.1 启动页

- 调用 `wx.login`，换取业务 token。
- 读取启动参数中的 `roomCode`、`invite` 或 `scene`。
- 登录成功后跳首页或目标房间预览页。
- 登录失败显示重试；不可无限自动重试。

### 2.2 首页

- 主按钮：创建房间、加入房间。
- 最近房间最多显示 5 个，区分“进行中”“已结束”。
- 展示昵称、版本、协议和隐私入口。
- 首次进入不强制获取微信头像和昵称。

### 2.3 创建房间

字段：

- 房间名称：1～20 个字符，默认“我的牌局”。
- 房间内昵称：1～10 个字符。
- 最大人数：V1 固定 10，不暴露设置。

成功后直接进入房间，创建者成为房主。

### 2.4 加入房间

支持三种入口：

- 手工输入房间号。
- 微信分享卡片。
- 小程序码 `scene`。

加入前显示房间名称、房主、当前人数和状态。关闭、满员或无效邀请应分别提示。

### 2.5 房间页

- 导航区：房间名称、房间号、连接状态、分享。
- 成员区：头像、昵称、房主标记、我的标记、余额。
- 快捷说明：点击其他成员即可记账。
- 动态区：加入、退出、改名、记账、撤销、关闭。
- 底部操作：流水、结算、设置。

成员头像继续采用昵称生成的本地图形，不上传头像素材。

### 2.6 新增记账

- 目标成员由入口带入，可切换。
- 金额只允许两位小数，转换为整数分提交。
- 可选备注，最长 50 字。
- 确认页明确显示“你 → 对方”。
- 提交按钮生成 UUID 幂等键；接口返回前禁止重复点击。

### 2.7 流水页

- 按时间倒序分页，每页 30 条。
- 支持“全部”“与我相关”过滤。
- 显示操作者、双方、金额、备注、时间和撤销状态。
- 不做客户端余额重算，以服务端快照为准。

### 2.8 结算页

- 成员按余额从高到低排列。
- 展示总流水数、总流转金额、开始和结束时间。
- 可生成适合微信分享的结算摘要图；摘要图不包含 OpenID 等内部信息。
- 关闭房间必须二次确认。

## 3. 核心流程

### 创建房间

```text
首页 → 创建房间 → 输入房间名和昵称 → 提交
→ 后端创建房间和房主成员 → 返回快照
→ 连接 WebSocket → 订阅房间 → 展示房间页
```

### 分享加入

```text
收到分享 → 小程序启动 → 静默登录 → 校验邀请 token
→ 房间预览 → 输入昵称 → 加入 → 订阅房间
```

### 记账

```text
点击成员 → 输入金额和备注 → 确认 → REST 提交
→ 服务端事务写入 → 返回新快照版本
→ Redis/WSS 通知其他成员 → 其他成员刷新快照
```

### 撤销

```text
打开流水 → 选择可撤销记录 → 确认
→ 新增 reversal 反向流水 → 更新双方余额
→ 原记录标记已撤销 → 广播版本变化
```

## 4. 业务规则

### 房间

- 房间号由随机数字生成，建议 6 位；必须通过唯一索引处理碰撞。
- 不再使用“查询最大房间号 + 1”的生成方式，避免枚举和并发冲突。
- 房间最多 10 名有效成员。
- 房主不能直接离开；必须先转让房主或关闭房间。
- 普通成员离开后仍保留历史昵称和流水。
- 同一用户重新加入同一房间时恢复原成员记录，而不是新增成员。

### 昵称

- 长度 1～10，去除首尾空格。
- 同一房间内有效成员的规范化昵称唯一。
- 历史流水保存成员 ID；展示昵称优先取当前昵称，同时保存操作时昵称快照用于审计。

### 金额

- 最小 0.01，V1 单笔最大建议 99,999.99。
- 允许负余额，不允许 0 金额、自付或负数输入。
- API 与数据库统一使用整数分。

### 撤销

- 操作者在 5 分钟内可以撤销自己的记录。
- 房主在房间关闭前可以撤销任意有效记录。
- 一条记录只能撤销一次；撤销记录不能再次撤销。

## 5. 状态与错误文案

| 场景 | 用户文案 | 客户端动作 |
|---|---|---|
| token 失效 | 登录状态已更新，请重试 | 静默刷新并重放一次请求 |
| 房间不存在 | 房间号无效或房间已删除 | 返回加入页 |
| 房间关闭 | 本房间已结束，只能查看记录 | 进入只读页 |
| 房间已满 | 房间人数已满 | 停留预览页 |
| 昵称重复 | 这个昵称已有人使用 | 聚焦昵称输入框 |
| 重复请求 | 本次记账已经提交 | 使用首次成功结果 |
| 网络断开 | 网络不可用，暂不能记账 | 保留表单，不本地写账 |
| 实时连接断开 | 实时同步中断，正在重连 | REST 可用，后台重连 |
| 数据版本落后 | 数据已更新 | 拉取最新快照 |

## 6. 埋点

仅记录匿名业务事件，不记录备注全文和 OpenID：

```text
app_launch
login_success / login_failed
room_create_success / failed
room_join_success / failed
record_create_success / failed
record_reverse_success / failed
share_card
share_qrcode
socket_connected / disconnected / fallback
room_close
```

## 7. 审核与隐私材料

- 小程序名称、简介、截图和服务类目统一描述为聚会记分工具。
- 用户协议声明仅提供记账记录，不处理实际资金。
- 隐私政策列明微信登录标识、昵称、房间记录、设备和错误日志用途。
- 用户删除账户时匿名化用户标识；依法或按业务约定保留账目审计记录。
- 不申请非必要权限，不强制获取头像、手机号或通讯录。
